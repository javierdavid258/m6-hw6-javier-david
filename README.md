# M6 HW6 - CSS Positioning, Pseudo-Elements, and Pseudo-Classes

- Repository: https://github.com/javierdavid258/m6-hw6-javier-david
- Live site: https://javierdavid258.github.io/m6-hw6-javier-david/

## Implemented features

1. **Sticky hero banner** – `main > section.hero` uses `position: sticky; top: 0;` with a `z-index` so it stays at the top of the viewport while the article scrolls beneath it.
2. **Drop cap** – `main > article > p:first-of-type::first-letter` enlarges and floats the first letter of the first article paragraph in a serif font.
3. **CSS tooltips** – the three red `span.tooltip` triggers reveal their inner span as a dark word bubble with a CSS triangle arrow on `:hover` and `:focus`, using relative/absolute positioning and a fade transition.

## Files
